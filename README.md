# noticed-skills

the skills that make your agent fluent in noticed.

## connect noticed first

these skills call the noticed mcp. connect it before you install, or the skills will not have anything to talk to.

setup guide: https://www.noticed.so/docs/mcp

## install
/plugin marketplace add noticedso/skills
/plugin install noticed-skills@noticed-skills
